- [深浅背景预览](深浅背景预览.png)：96、44、32 CSS 像素对照；这是素材预览，不是网站已替换后的截图。
- 检查八张原图的透明通道，均含完全透明像素与不透明主体；八张网页文件可被浏览器解码加载。
- 已实际查看深浅背景对照，主要形状在 44 与 32 像素下可辨认；未将大图生成成功等同于页面接入完成。
- WebP 只作等比缩小与格式转换，没有另行手工抠图或裁切；保留原始生成 PNG。
- 个别原图边缘仍有轻微生成式色边，小尺寸对照中不明显；如用于大幅品牌物料，应重新检查原图边缘。
