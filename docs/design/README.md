## 开发时先看什么

1. 阅读仓库根目录 `AGENTS.md`、[开发交接文档](../CODEX_HANDOFF.md) 和本文。
2. 用图像查看工具打开 [完整首页](知行合一个人导航仪表盘.png) 与 [搜索态](玉山湖畔的量化探索导航.png)，不能只根据文件名或文字描述还原设计。
3. 完整首页用于页面分区、插画氛围、留白和层次；搜索态只用于输入后悬浮结果面板的分组、关键词高亮及位置。
4. 实现前同时阅读 [网页素材说明](../../site/assets/images/素材说明.md)。完整界面图不是网页背景原图，禁止将其当作一个 `<img>` 替代实际页面，也不要把带文字的裁切图冒充独立原图。

## 确认版本与例外

- 完整首页：`知行合一个人导航仪表盘.png`，原对话图片查看器的第 6 张。用户在图后回复“可以这个版本”，随后补充“唯一的就是不需要右上角的头像”。归档原文件保留头像，开发时移除顶部头像；保留 Banner 人物和关于我人物。
- 搜索态：`玉山湖畔的量化探索导航.png`，同一查看器的第 7 张。用户提出“搜索框里输入后的效果图”，图片后回复“可以，你看了n8n吗”。原图仍包含旧身份标签、工具并排、项目与关于我并排等细节；仅参考搜索浮层，不据此回退完整首页布局。
- 其余 6 张原文件放在 `历史稿/`，按本轮“先全部下载下来”的要求归档；不是新的定稿，不覆盖已经确认的修改。
- 图片中的站点数量、项目表现、搜索结果与文案是示例。真实数据与功能以代码、实际 JSON 和用户明确需求为准。

## 已确认的视觉与布局要求

- 山川湖泊夕阳的大幅 Banner，右侧岩石人物，主文案“知行合一”；人物原图尚未取得。
- 顶部菜单：首页 / 导航 / 工具 / 项目 / 关于；右侧搜索和主题切换，不放头像。
- 顺序：Banner → 常用入口 → 我的工具 → 网站导航 → 我的项目 → 关于我。各区独立全宽纵向排布；项目和关于我不并排。
- 不加“开发者 / 量化交易 / AI 探索 / 生活记录”身份标签。
- 点击分类在当前板块收缩分类入口并展开书签，不跳新页，不重复所选分类的大标题；书签和项目支持横向浏览。
- 顶部搜索输入后在当前页显示分组浮层；分类内搜索只搜索该分类。
