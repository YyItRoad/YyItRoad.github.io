# 项目图标

由用户自行上传图标文件到此目录，不提供上传系统。当前四个名称为 `quant.svg`、`diary.svg`、`automation.svg`、`video.svg`；文件尚未上传时显示统一内置默认图标。

`projects.icon` 只填英文字母、数字、下划线或短横线组成的文件名，可带小写 `.svg/.png/.webp/.jpg/.jpeg` 后缀，不带后缀默认 `.svg`。不支持 URL、目录、空格、HTML 或查询串。文件名大小写须与实际文件一致。仅上传自己信任且有权使用的图片；SVG 通过图片元素加载，不以内联 HTML 执行。

整合说明（2026-10-23）：自定义文件成功后优先显示；当前四个既有项目的缺文件回退复用已确认的 3D 图标，其他名称使用统一项目栏目图标。卡片和搜索采用相同规则，用户无需维护新增映射表。
