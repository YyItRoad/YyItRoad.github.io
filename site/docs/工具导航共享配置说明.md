# 工具导航共享配置说明

日期：2026-10-22。首页工具卡片、全局搜索和工具详情页底部导航，统一读取 `site/assets/js/data.js` 的 `tools` 列表。

## 新增工具的显示行为

在 `tools` 中新增记录后，首页和全局搜索、所有现有详情页底部导航随之更新。详情页顺序与首页相同，按 `id` 和 `body[data-tool]` 匹配当前工具，通过 `aria-current="page"` 高亮。

导航使用相对于工具模块的站点根路径解析 `url`，支持根目录或独立子目录托管。标题通过 `textContent` 呈现，图标使用固定本地映射和现有 SVG 回退。

四个 HTML 文件仅保留导航容器，不再重复维护固定链接。网页脚本入口已更新内容指纹。

## 仍需维护的内容

- 工具配置：`id`、`title`、`description`、`tags`、`url`。
- 实际工具页面及其处理逻辑，不会由导航配置自动生成。
- 专属图标：在 `asset-icons.js` 中登记相应本地图片；没有登记时显示通用 SVG。

## 验证结果

原有功能和新增扩展检查共 18/18 组通过。扩展检查仅在浏览器临时加入第五、第六个工具，验证首页六张卡片、搜索两条新增结果、四个详情页六项导航、各自唯一当前页标记、正确链接和 320px 无横向溢出。

原有首页十二个图标、详情页标题图片、搜索、图片失败回退和深浅主题检查均通过。正式工具列表仍为原来四项，没有加入演示记录。
