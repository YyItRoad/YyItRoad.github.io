# 工具页视觉一致性验收

日期：2026-10-22。范围：AES 加解密、JSON 格式化、日期时间戳、Base64 / URL 编解码四个工具页。

## 发现与修正

1. 工具页左上角仍是旧星形字符，现改为与首页相同的 `iconSVG('mountain')`，直接复用 `icons.js` 三条山形路径；网站 favicon 保持原山形。
2. 工具标题图标原已复用首页透明 WebP，本次确认四页均使用正确文件，保留桌面 64 / 手机 52 像素的比例。
3. 页底工具切换原仅有文字，现增加与首页一致的四个图标，并保留当前工具的 `aria-current="page"` 高亮。桌面四列、小屏两列，链接行为不变。
4. 顶栏统一品牌字重、山形尺寸、圆形主题按钮与半透明模糊背景；页面底色沿用首页浅色、深色柔和渐变。标题、表单、说明卡片与工具切换保留统一间距和圆角。
5. 工具页 CSS、脚本入口已更新内容指纹，避免旧缓存造成视觉错配。

## 检查结果

- 原有 Chromium 端到端检查 17/17 组通过，涵盖四种工具处理、错误提示、加解密兼容、复制回退、无输入外发、隐私模式、子路径部署与响应式布局。
- 四页逐一检查 1440、768、390、320 像素及深浅主题：标题图标和页底四图均成功加载，映射与链接一致，当前页标记正确，无横向溢出，顶栏品牌与操作按钮不重叠。
- 检查首页十二个图标、搜索与详情页图标、图片加载失败回退，均通过，无未捕获页面 JavaScript 错误。
- 已实际打开 JSON 桌面浅色、加解密手机深色、时间戳手机浅色与编解码桌面深色截图，确认品牌、图标、卡片和导航的实际观感。
- 四个工具各自的桌面与手机深浅截图保存在本地 `docs/design/工具页视觉一致性/页面预览/`。

## 修改边界

复用现有图标，没有新生成图片，没有修改工具运算逻辑、首页数据、书签 favicon、栏目图标或品牌山形路径。仅提交开发分支，本次未部署正式站。
