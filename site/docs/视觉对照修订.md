# 首页视觉对照修订

日期：2026-10-22。针对“实现出来的效果和设计效果差得有点远”的反馈，重新实际打开本地完整首页确认稿和搜索态参考，按 1024px 同尺寸与 1440px 桌面截图检查。以运行中的网页为交付对象，保持功能和真实数据。

## 本轮修正

| 对照项 | 修订前 | 修订后 |
| --- | --- | --- |
| 内容区最大宽度 | 1160px，宽屏两侧留白过大 | 1320px；小屏保留边距 |
| 头部与 Banner | 72px 头部、420px Banner，首屏偏高 | 64px 头部、约 300px 桌面 Banner；人物、湖面与夕阳向上校准 |
| 插画与白色板块 | 背景在 Banner 结束处切断，面板纯白且高 | 插画延续至常用入口背后，面板轻微透明、模糊与柔和渐变，减少纵向空白 |
| 搜索 | 已调整为半宽居中 | 保留半宽居中，并与结果浮层同宽 |
| 常用图标 | 远程 favicon 不稳定，容易出现字母占位 | 已归档四个官网品牌图标，ChatGPT 使用保持原始轮廓的绿色派生版 |
| 工具区 | 1024px 提前变为两列，块高偏大 | 1024px 保持四列，缩小图文间距和卡片高度；手机仍为两列 |
| 网站导航 | 默认折叠、分类三列，和确认图的展开态差异大 | 默认展开真实开发技术分类，分类为可横向浏览的一行，保留未知分类入口 |
| 项目区 | 通用字符图标、描述占多行 | 独立 SVG 图形、紧凑描述、真实标签；保留横向浏览与键盘操作 |
| 关于我 | 段落偏长，视觉偏重 | 精简为真实技术方向，保留人物与山形签名，减少装饰标签 |
| 导航激活态 | 布局变化时可能误高亮后面的板块 | 按实际滚动位置更新，初始页面正确高亮首页 |

## 验证与边界

完整 17 组端到端测试覆盖原有功能；另人工查看桌面、手机、深色与搜索浮层截图。JS 语法与变更空白检查通过。正文测试结果见 [自动化测试结果](自动化测试结果.md)。

当前只有 7 条真实书签、3 个收藏入口，开发技术分类只有 GitHub 与 Vue 两条。确认效果图中的 9 个收藏和 9 个开发网站是演示内容；因此实际卡片数量与密度仍不同，没有为填满界面虚构数据。

插画使用前一轮按参考重新生成的独立素材，构图和风格接近，不是历史确认稿的原始图层，不能声称逐像素一致。本轮没有重新生成图片，也没有修改线上服务或部署。
